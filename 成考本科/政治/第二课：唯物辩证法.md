# 唯物辩证法的总特征和基本规律及基本范畴

## 唯物辩证法的总特征

联系的观点和发展的观点是唯物辩证法的两个总特征

事物的普遍联系
1. 联系具有普遍性
2. 联系具有客观性
3. 联系具有条件性
4. 联系具有多样性

事物的运动、发展、变化

发展 != 变化 != 运动

发展的含义是事物由低级向高级，由简单向复杂的前进的上升的运动
发展的实质是：新事物的产生和旧事物的灭亡

为什么新事物一定会战胜旧事物（必然性）
新事物：合乎历史前进方向、具有远大前途的东西
新事物是在旧事物的母胎中，孕育成熟的、具有生命力的事物
旧事物：丧失历史必然性、日趋灭亡的东西
## 唯物辩证法的基本规律

### 对立统一的规律（动力和源泉）（矛盾规律）
矛盾是反映事物内部和事物之间对立统一关系的哲学范畴
对立和统一分别体现了矛盾的两种基本属性

矛盾的同一性
1. 矛盾双方互相依存（谁也离不开谁）
2. 矛盾双方互相包含（你中有我，我中有你）
3. 矛盾双方可在一定条件下相互转化（尺有所短，寸有所长）

矛盾的斗争性（对立性）
1. 矛盾双方互相排斥（同而不和）
2. 矛盾双方互相分离（和而不同）

同一性和斗争性的辩证关系
1. 相互联结，相辅相成
2. 同一性、斗争性互为前提互为条件
3. 斗争性寓于同一性之中，同一性通过斗争性来体现
4. 斗争性是绝对的，无条件的，永恒的，同一性是相对的，有条件的，暂时的

矛盾的同一性在事物发展中的作用
1. 同一性使矛盾双方互相吸取有利于自身的因素。在互相作用中各自得到发展
2. 同一性是事物存在的发展和前提
3. 同一性规定着事物转化的可能和发展的趋势、

矛盾的斗争性在事物发展中的作用
1. 矛盾双方的斗争促进矛盾双方力量的变化。竞长增高、此消彼长，造成双方力量发展的不平衡，为对立面的转化、事物的质变创造条件。
2. 矛盾双方的斗争是一种矛盾统一体向另一种矛盾统一体过度的决定力量。

矛盾的普遍性和特殊性是一般和个别，共性和个性对立统一的关系，是事物矛盾问题的精髓，是我们掌握唯物主义辩证法的关键 

### 质量互变规律（状态和形式）
质 和 量的关系
质是指一种事物成为它自身并使它区别于其他事物的一种内在规定性
量是指事物存在和发展的规模、程度、速度以及构成事物的成分在空间上的排列组合等可以用数量表示的规定性
度就是事物保持自己质的量的限度，是和事物的质相统一的限量。在这个界限内，量的变化不会引起质的变化，超过这个限度，事物的质就会变化。

量变：指事物数量的增加和次序的变动，是保持事物的质的相对稳定的不显著变化
质变：指事物性质的根本变化，是事物由一种质态向另一种质态的飞跃。区分质变和量变的标志是看是否超出度的范畴。

量变和质变的辩证关系：对立统一
1. 量变是质变的必要条件。没有量的积累，就不会有质的飞跃
2. 质变是量变的必然结果。量变达到一定程度，必然引起质变
3. 量变和质变是互相渗透的

质量互变规律的方法论意义
1. 既然任何事物都是质与量的统一，就要把对事物的定性研究和定量研究结合起来，定性研究是认识基础，定量研究是认识深化和精确性
2. 既然任何事物都有自己特定的度，就要使我们的认识和实践与事物本身的度相适合，掌握适度原则（掌握火候，过犹不及，把握分寸）
3. 既然任何事物的发展变化是量变与质变的统一，就要处理好量变与质变的关系，既要重视点滴的积累，又要善于抓住机遇，将事物推向新的发展阶段

### 否定之否定规律（趋势和道路）
事物发展的道路是由否定之否定规律揭示的由于内部矛盾的推动，事物由自我肯定状态达到自我否定的状态，进而在由这种否定状态发展到新的否定即否定之否定状态，从而开辟出自我发展和自我完善的道路，这就是事物发展中的否定之否定规律

肯定方面和否定方面
肯定方面是事物中维持其存在的方面。
否定方面是事物中促使其灭亡的方面。

辩证否定观
1. 否定是事物的自我否定、自我发展
2. 否定是事物发展的环节
3. 否定是新旧事物联系的环节
4. 辩证否定的实质是扬弃

事物的辩证否定不是一次完成的，而是经历事物的自我发展的两次否定、三个阶段，即“肯定 - 否定 - 否定之否定”的有规律的过程
否定之否定规律揭示了事物发展的前进性与曲折性的统一
