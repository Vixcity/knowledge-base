## 函数的定义、性质与运算
三要素：定义域，对应法则，值域

定义域是自变量x的取值范围，相当于入参
对应法则就是f的具体表达式，即运算关系，相当于函数体
值域是因变量y所有的可能取值，相当于返回值

## 函数的四大基本性质
单调性，奇偶性，周期性，有界性

单调性：
	定义：单调性在函数区间内的增减趋势，若x1 < x2,则f(x1) <= f(x2) 为递增，反之为递减

奇偶性：
	定义：奇函数满足f(-x) = -f(x) 图像关于原点对称
		 偶函数满足 f(-x) = f(x) 图像关于y轴对称

周期性：
	定义：存在一个最小的正整数T，使的f(x+T) = f(x) 对定义域内所有x成立，一定是有规律的

有界性：
	定义：指存在正数M，使的|f(x)| <= M 对定义域内所有x成立，即应变量有一个范围

## 复合函数
复合函数表示先作用里面的函数再作用外层的函数，相当于高阶函数，内层函数的值域，必须再外层函数的定义域内，这就是复合函数有意义的关键，就是里层的返回值，作为外层的入参

## 反函数
反函数是单设函数f的逆映射，满足f^-1(f(x)) = x，体现函数的可逆性
举个栗子：y = 1/x => x = 1/y，所以x和y互为反函数

## 求导公式
1. 常数函数：若y=C（C为常数），则y' = 0
2. 幂函数：若y=x^n(n为实数)，则y' = $$nx^{n-1}$$

3. 指数函数：
	- 若y=a^x(a>0且a!=1)，则y' = $$a^x lna$$
	- 特别的，当a=e时，y=$$e^x$$，y' = $$e^x$$ 
4. 对数函数：
	- 若y=$$log_ax$$(a > 0 且 a != 1，x > 0)，则y' = $$\frac{1}{xlna}$$
	- 当a=e时，y=lnx，y'=$$\frac{1}{x}$$
5. 三角函数：
	- 若y=sinx，则y' = coxx
	- 若y=cosx，则y' = -sinx

## 极限的定义
设函数y=f(x)在点x0的某个邻域内有定义，当x无穷趋于x0时，f(x)无限趋近常数A，则称A为f(x)当x->x0时的极限，记作
$$\lim\limits_{x->x0}f(x)=A$$
例如：
$$\lim\limits_{x->2}f(2x-4)=0$$
2x-4的值无限接近0，这个定义是理解极限的基础

## 极限的四则运算
如果有
$$\lim\limits_{x->x0}f(x) = A, \lim\limits_{x->x0}g(x) = B$$
则

1. $$\lim\limits_{x->x0}[f(x)±g(x)] = \lim\limits_{x->x0}f(x) ± \lim\limits_{x->x0}g(x) = A ± B$$
2. $$\lim\limits_{x->x0}[f(x)·g(x)] = \lim\limits_{x->x0}f(x) ·  \lim\limits_{x->x0}g(x) = A · B$$
3. 当 B != 0 时(分母不为0)，
	$$
	\lim\limits_{x->x0}\frac{f(x)}{g(x)} = \frac{\lim\limits_
	{x->x0}f(x)}
	{\lim\limits_{x->x0}g(x)}
	= \frac{A}{B}
	$$

## 无穷小量与无穷大量
无穷小量定义：对于函数$$y=f(x)$$，如果当x在某个变化过程中，函数f(x)的极限为0，则称在该变化过程中，f(x)为无穷小量，记作$$\lim\limits_{x->x0}{f(x)=0}$$

无穷大量定义：对于函数$$y=f(x)$$，如果当x在某个变化过程中，函数f(x)的极限值越来越大，则称在该变化过程中，f(x)为无穷大量，记作$$\lim\limits_{x->x0}{f(x)=\infty}$$

无穷大量与无穷小量的关系：

在同一变化中，如果发f(x)为无穷大量，且f(x)!=0，则$$\frac{1}{f(x)}$$为无穷小量

在同一变化中，如果发f(x)为无穷大量，且f(x)!=0，则$$\frac{1}{f(x)}$$为无穷小量

无穷小量的性质：
	1. 有限个无穷小量的代数和仍是无穷小量
	2. 无穷小量与有界函数的积仍是无穷小量

## 无穷小量的比较与替换
定义：α，β，是同一变化过程中的无穷小量，即limα = 0，limβ = 0

1. 如果$$lim\frac{α}{β} = 0$$，则称β是α比较高阶的无穷小量
2. 如果$$lim\frac{α}{β} = \infty$$，则称β是α比较低阶的无穷小量
3. 如果$$lim\frac{α}{β} = c ≠ 0$$，则称β是与α同阶的无穷小量
4. 如果$$lim\frac{α}{β} = 1$$，则称β与α等阶的无穷小量
